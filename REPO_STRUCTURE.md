# Repository structure (v3)

Minimal reproduction package.  **No third-party data is shipped**: `data/` holds only
the two mapping tables, and `fetch_datasets.bat` downloads and prepares every dataset
from its official record.  Everything under `results/`, `outputs/` and `figures/` is
generated by `run_all.bat`; the produced tables and figures are archived once per
release in `release/results_and_figures_v1.0.1.zip`.

```
repo_v3/
├── fetch_datasets.bat          step 0: download + prepare the datasets
├── run_all.bat                 step 1: reproduce every number and figure
├── run_all_except_VirtualLibrary.bat   same, without the virtual-library step
├── hte/params.json            run-wide hyper-parameter overrides (read by hte/params.py)
├── LICENSE / LICENSE-DATA      MIT for code; per-source licences for the data
├── CITATION.cff / .zenodo.json
├── README.md / REPO_STRUCTURE.md / requirements.txt / .gitignore
├── archive/                    the frozen pipeline (reference implementation)
├── data/                       the two mapping tables only
├── hte/                        the algorithm package
├── scripts/                    the producers
├── tests/                      equivalence tests against archive/
└── docs/                       reference material (index in docs/README.md)
```

## Root files

| File | Purpose |
|---|---|
| `fetch_datasets.bat` | Licence gate -> downloads AI_RCP, bh-hte-ood, Summit, DoyleHTE, Roche66k -> prepares them (Roche split into 8, Summit merged 385/96, DoyleHTE cut to the 15x20 grid). Optional rxn_yields, local use only. |
| `run_all.bat` | 11 steps: grid/Table 1 -> stats -> enrichment -> transfer -> protocols -> Table 2 -> section 3.6 -> virtual library -> attribution -> figures -> 63-number gate. Refuses to start when `data/` holds no datasets. |
| `run_all_except_VirtualLibrary.bat` | The same without the virtual-library step. |
| `hte/params.json` | Hyper-parameters exported from the frozen pipeline (`TEST_SIZE`, `RF_N_ESTIMATORS`, `HISTGB_MAX_ITER`, the ensemble-weighting constants) plus `_split` / `_models` / `_encodings` metadata. `hte/params.py` reads it **from `hte/`** (same directory, `PARAMS_JSON = Path(__file__).parent / "params.json"`) and lets it **override the built-in defaults**, so this is the one file you edit to change a knob without touching code. It is never written by the code. It lives inside the package because it is imported together with `params.py`, not at the repository root. |
| `LICENSE` | MIT, for the code. |
| `LICENSE-DATA` | Per-source licence table (MIT / Apache-2.0 / CC BY 4.0 / CC BY-NC 4.0 / AAAS Default License), the obligation attached to each, and the preparation each dataset needs. |
| `CITATION.cff`, `.zenodo.json` | Release metadata. |
| `requirements.txt` | numpy, pandas, scikit-learn, xgboost (`xgboost-cpu` build), scipy, matplotlib, rdkit, pyarrow, openpyxl, seaborn, tqdm, Pillow, torch (CPU wheel recommended). |

## `data/` - the only files that ship

> `data/col_mappings.csv` also carries a few rows for files that are **not** part of the
> thirteen-dataset corpus (`(Suzuki-Coupling-ML)…`, which has `corpus: false`, and the two
> extra `(bh-hte-ood)` exports).  The loader never reads them.  The SMILES columns of every
> dataset pass through unchanged as `reactant_1_smiles` / `reactant_2_smiles`; they are
> reported as features but never encoded as categorical slots.


| File | Purpose |
|---|---|
| `col_mappings.csv` | raw column -> semantic slot, with per-file overrides (`disable` drops a slot for one file). |
| `alias_mapping.yaml` | alias -> source file stem, plus `corpus:` / `donor:` / `structure:` / `case_study:` flags. |

Everything else in `data/` is produced by `fetch_datasets.bat`.

## `hte/` - the algorithm package (15 modules)

`hte` must be imported **before** numpy/xgboost: `__init__.py` pins the BLAS/OpenMP
thread count, and without that the XGBoost grid cells drift.

| Module | Purpose |
|---|---|
| `__init__.py` | Package entry: thread caps, public API. |
| `v16_core.py` | The core: `load_real_dataset`, `prepare_features`, `get_split_positions`. |
| `data.py` | Dataset parsing, catalyst/ligand split, loading-axis resolution. |
| `mapping.py` | Applies `data/col_mappings.csv` (per-file override beats global alias). |
| `metal_reading.py` | Reads the catalytic metal per row, SMILES evidence first. |
| `params.py` | Parameter registry (`params.json` overrides the defaults); slot constants. |
| `datasets.py` | Parses `alias_mapping.yaml`: alias -> file, corpus/donor flags. |
| `features.py` | Feature matrix and the three encodings. |
| `ceiling.py` | Noise ceiling `R2max = 1 - s2within/s2total`. |
| `models.py` | Estimator factories for the five architectures. |
| `grid.py` | The 12-configuration grid runner. |
| `attribution.py` | SHAP and permutation importance. |
| `recommend.py` | Ranking measured records, deduplication, model-agreement gate. |
| `virtual.py` | Virtual library: enumeration, loading grid, batched prediction, EI. |
| `rank_real.py` | Route-1 ranking (`generate_figure6_direct_ranking`). |

## `tests/` - equivalence against `archive/` (7 files)

Not called by `run_all.bat`; run them by hand (`python tests\test_data_features.py`)
or all at once (`python tests\run_equivalence.py`).

| File | Check |
|---|---|
| `_common.py` | loads `archive/single_dataset_full_benchmark.py` as the reference; registers known divergences |
| `run_equivalence.py` | runs the four suites in order |
| `test_data_features.py` | loader + feature parity (24 checks, 21 documented divergences) |
| `test_ceiling.py` | ceiling and Table 1 (23 + 22) |
| `test_grid_one_dataset.py` | grid recomputation (11 + 5) |
| `test_attribution.py` | attribution values (9) |
| `test_recommend.py` | recommendation output (12) |

## `archive/`

| File | Purpose |
|---|---|
| `single_dataset_full_benchmark.py` | The frozen pipeline that produced the paper. No script imports it at run time; it is kept as the reference implementation for `tests/` (and for `tables.py --rebuild`). Do not edit it to match `hte` - the divergences are what the tests measure. |
